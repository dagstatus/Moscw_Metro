# Метро Москвы — офлайн-схема и маршруты для Android

Приложение сразу открывает схему метро. Внизу два поля «Откуда» и «Куда». Маршрут с пересадками строится на телефоне, интернет не нужен (у приложения нет даже разрешения на интернет). Есть светлая и тёмная тема: кнопка ◐ справа вверху переключает «как в системе → светлая → тёмная».

На схеме: 16 линий метро, МЦК и МЦД-1…4, всего 452 станции и 185 пересадок. Данные актуальны на **08.10.2026**: Рублёво-Архангельская линия (открыта 05.09.2026), Троицкая до «ЗИЛа», монорельс и закрытые станции не показаны.

## Установка на телефон

1. Скопируйте `dist/metro-moscow-<версия>.apk` на телефон (через кабель, Telegram «Избранное», облако и т. п.).
2. Откройте файл и разрешите установку из этого источника, если телефон спросит.

## Как обновить схему и выпустить новую версию

Нужно один раз установить **Android Studio** (https://developer.android.com/studio). Она поставит Java и Android SDK, которые использует инструмент. Сам Android Studio открывать не обязательно.

1. Отредактируйте таблицы в папке `data/` (открываются в Excel, разделитель «;», кодировка UTF-8):
   - `lines.csv` — линии;
   - `stations.csv` — станции;
   - `transfers.csv` — пересадки;
   - `info.properties` — дата актуальности и источник (показываются в приложении в окне «О приложении»).
2. Запустите `update.bat` (Windows) или `update.sh` (macOS / Linux) и выберите пункт:
   - **1 — Проверить данные.** Найдёт опечатки: несуществующие линии и станции в пересадках, неверные координаты, станции, до которых нельзя доехать.
   - **2 — Открыть схему в браузере.** Так можно посмотреть, как изменения лягут на карту, ещё до сборки.
   - **3 — Собрать тестовый APK.** Версия не меняется, файл получит суффикс `-test`.
   - **4 — Выпустить обновление.** Поднимает номер версии, собирает подписанный APK в `dist/`. Его можно ставить поверх старой версии, история и настройки сохранятся.

Команды можно вызывать и напрямую: `update.bat check | preview | apk | release`.

### Таблица `stations.csv`

| столбец | что писать |
|---|---|
| `line` | номер линии из `lines.csv` (`1`, `8А`, `14`, `D2`…) |
| `name` | название станции |
| `lat`, `lon` | широта и долгота (например, `55.757228` и `37.615078`; можно взять в Яндекс Картах) |
| `prev` | обычно пусто: станция соединяется с предыдущей строкой той же линии. Для ответвления впишите название станции, от которой оно идёт (так сделана ветка Филёвской линии «Киевская → Деловой центр → Москва-Сити»). `-` означает «не соединять с предыдущей» |
| `minutes` | время в пути от предыдущей станции, если хотите задать вручную. Пусто — рассчитается по расстоянию |
| `x`, `y` | ручное положение точки на схеме. Пусто — рассчитается из координат |

Станции одной линии идут подряд в порядке следования поездов. Новая станция в середине линии — новая строка между соседями.

### Таблица `lines.csv`

`id; name; color; type; ring; wait` — номер, название, цвет `#RRGGBB`, тип (`metro`, `mcc` или `mcd`; МЦК и МЦД рисуются двойной линией), `ring=1` для кольцевых линий, `wait` — среднее ожидание поезда в минутах (учитывается при пересадке).

### Таблица `transfers.csv`

`line1; station1; line2; station2; minutes` — пара станций и время перехода пешком в минутах. Если на узле три станции, нужны все три пары.

### Примеры

- **Открылась новая станция на существующей линии** — добавьте строку в `stations.csv` в нужное место, при необходимости пересадку в `transfers.csv`, затем пункт 4.
- **Открылась новая линия** — строка в `lines.csv`, её станции в `stations.csv`, пересадки в `transfers.csv`.
- **Станция закрылась** — удалите строку (и её пересадки). Если линия разрывается, у следующей станции поставьте `prev` = `-`.
- **Переименование** — поменяйте `name` в `stations.csv` и в `transfers.csv`.

## Telegram: Mini App и бот

В папке `docs/` лежит та же схема для Telegram (Mini App), в папке `bot/` — бот. Данные общие: `update.bat` (пункты 2–4) обновляет `docs/metro.json` вместе с APK.

**Mini App** — обычная веб-страница: схема, поиск станций, маршрут, светлая и тёмная тема (по умолчанию как в Telegram). После первого открытия работает без интернета. Публикуется через GitHub Pages:

1. На GitHub: *Settings → Pages → Build and deployment*: Source **Deploy from a branch**, ветка **main**, папка **/docs**. Адрес будет `https://dagstatus.github.io/Moscw_Metro/`.
2. В @BotFather: `/newbot` (если бота ещё нет), затем `/newapp` или *Bot Settings → Menu Button* и укажите этот адрес.

Чтобы обновить Mini App, выпустите версию через `update.bat` и отправьте изменения на GitHub (`git commit` и `git push`). Pages обновится сам.

**Бот** отвечает на сообщения вида «Митино — Выхино», «из Митина в Выхино», «Комсомольская, Деловой центр». Можно прислать одну станцию, потом вторую. Под ответом кнопки «Показать на схеме» (открывает Mini App с этим маршрутом) и «Обратно».

Запуск:

1. Установите Python 3.8+ (https://www.python.org). Сторонние библиотеки не нужны.
2. Скопируйте `bot/config.example.ini` в `bot/config.ini` и впишите токен от @BotFather и адрес Mini App.
3. Запустите `bot/run_bot.bat` (Windows) или `bot/run_bot.sh`.

Бот работает, пока запущен этот процесс. Чтобы он отвечал круглосуточно, запустите его на сервере (подойдёт любой VPS с Python). Схему бот раз в 6 часов скачивает с адреса Mini App, поэтому после публикации новой версии его не нужно перезапускать.

## Ключ подписи — храните его

При первой сборке создаётся папка `keystore/` с ключом. Все обновления должны подписываться **этим же ключом**, иначе Android не даст поставить новую версию поверх старой. Сделайте копию папки `keystore/` и не публикуйте её.

## Публикация

- **Раздать файлом / RuStore** — достаточно APK из `dist/`.
- **Google Play** требует AAB. Откройте папку проекта в Android Studio (Gradle-файлы уже есть) и выберите *Build → Generate Signed App Bundle*, указав ключ из `keystore/` (пароль в `keystore/keystore.properties`). Перед этим выполните пункт 4 в `update.bat`, чтобы данные и версия обновились.

## Устройство проекта

- `app/src/main/java/…/MetroMapView.java` — рисование схемы, жесты, подписи без наложений.
- `app/src/main/java/…/Router.java` — поиск маршрута (алгоритм Дейкстры). Время = перегоны + переход пешком + среднее ожидание поезда.
- `app/src/main/java/…/MainActivity.java` — экран, поиск станций, темы.
- `app/src/main/assets/metro.json` — данные схемы. **Не редактируйте вручную**: файл собирается из `data/` инструментом `tools/Build.java`.
- Внешних библиотек нет, APK весит около 60 КБ, работает на Android 8.0 и новее.
